How does hiding work?

In hide mode, your server fetches the page or file and passes it to the visitor, so the address bar keeps showing your link. Clicking links inside a proxied web page may still go to the real site. Hide mode works best for files, PDFs, images, and videos. Redirect mode is faster and works with every site.
